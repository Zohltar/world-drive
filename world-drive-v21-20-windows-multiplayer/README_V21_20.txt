WORLD DRIVE V21.20 — WINDOWS MULTIPLAYER

Base : V21.19 stable.

Ajouts :
- Héberger une session LAN directement dans l'application Windows.
- Affichage automatique des IPv4 LAN du PC hôte.
- Se connecter à une session avec IP ou nom du PC hôte.
- Proxy local Electron pour conserver le client WebSocket historique intact.
- Bouton Arrêter pour fermer proprement serveur/proxy.
- Preload Electron sandboxé + IPC limité aux quatre actions multijoueur.

Gameplay / route / terrain :
- terrain.js identique à V21.19.
- logique de route V21.19 conservée.
- aucune collision multijoueur ajoutée.

Port LAN par défaut : TCP 8081.
