WORLD DRIVE V21.22.3 — HITCH-FREE STREAMING VALIDATION

STATUS
Development candidate. Stable baseline remains V21.21.27.

TARGET
Eliminate the recurring 2–10 second micro-stutter pattern reported while FPS
otherwise remains very high (~140+ FPS on the RTX 3080 test machine).

ROOT-CAUSE PATHS ADDRESSED
- Ahead DEM completion no longer schedules rebuildLocalWorld every >=2.4 s.
- DEM/hydro async completion no longer directly rebuilds full world geometry.
- Normal floating-origin 520 m recenter is O(1) render-space translation.
- Full world regeneration is coalesced and prefers calm vehicle state.
- Active-driving proactive imagery mosaic refresh is disabled; warm cache remains.
- Static shadow maps refresh on world mutation, not a periodic timer.
- 5 s perf console log disabled by default.

VISUAL / PHYSICS SCOPE
- No terrain quality reduction from V21.22.2.
- No vehicle physics changes.

QUIET DIAGNOSTIC
After a driving test, run in the browser console:
  WorldDriveFramePacing()
The function does not print periodically. Useful fields:
- hitchCount: frames >20 ms since launch
- maxFrameMs: worst observed frame interval
- pendingWorldRefresh / pendingReasons
- worldBuildCenter / worldOffset

USER TEST
1. Same route and camera where the 4–5 s micro-stutter was obvious.
2. Drive continuously for at least 60 seconds at normal and high speed.
3. Do not keep DevTools Performance recording during the subjective test.
4. Observe whether the old periodic cadence disappears.
5. If any hitch remains, run WorldDriveFramePacing() once after the test.
