# Civil traffic vehicle pack

Expected runtime asset:

`assets/traffic/generic_passenger_car_pack_traffic.glb`

Fallback filename supported by the runtime:

`assets/traffic/generic_passenger_car_pack.glb`

The traffic system remains functional with the Hyundai Sonata alone if the pack is absent. When the pack is present, ten additional civilian silhouettes are added to the spawn pool: compact, coupe, hatchback, minivan, off-road, pickup, sedan, sport, SUV and wagon.
